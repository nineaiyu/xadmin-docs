# 功能特性总览

> 一页看全 xadmin 的能力地图：**默认全部开启**，可一条配置裁剪（见
> [功能裁剪（模块化）](../advanced/module-trim)）。本文的模块清单以后端仓库
> `packages/xadmin-common/common/core/modules/catalog.py` 为唯一事实源。

## 一、能力地图

| 领域 | 能力 | 模块 |
|------|------|------|
| 身份与访问 | 登录 / 注册 / 密码重置 / 会话管理 / MFA 多因素认证 / 第三方登录（OAuth）/ IM 扫码登录 | 内核 |
| 组织与权限 | 用户 / 角色 / 菜单 / 部门 / 字典 / **数据权限**（行级）/ **字段权限**（列级） | 内核 |
| 系统配置 | 站点外观 / 安全策略 / 消息渠道 / 页面水印 / 个人配置 | 内核 |
| 文件与流转 | 附件中心 / 在线预览 / 导入导出 / 下载中心 / 可插拔存储（local / S3） | 内核 |
| 通知 | 站内通知中心、多渠道消息偏好 | 内核 |
| 审计 | 操作日志 / 登录日志 / 在线用户 / 行级变更历史 | 内核 |
| 个人凭证 | 个人访问令牌（PAT） | 内核 |
| 审批 | 敏感操作审批（拦截 + 审批单 + 多级规则）、审批流引擎（流程定义 / 实例 / 委托 / 请假） | 标配 + 可选 |
| 数据治理 | 数据脱敏规则 | 标配 |
| 目录同步 | LDAP / AD 同步、SCIM 2.0 | 标配 + 可选 |
| 运维监控 | 主机监控 / 定时任务管理 / Flower 任务面板 | 标配 |
| 协作 | 聊天室（消息 / 附件 / 线程回复） | 可选 |
| AI | AI 助手（问答 / NL 查数 / 受限动作）、知识库（向量检索）、MCP 服务接入 | 可选 |
| 数据分析 | 数据集 / 仪表盘 / 报表（定时）/ 数据大屏（自由画布） | 可选 |
| 表单 | 表单采集设计器 / 我的填报 / 表单数据管理 | 可选 |
| 集成 | 事件订阅（出站 Webhook）、开放平台（API 应用 + OAuth 授权码）、全局搜索 | 可选 |

## 二、框架级能力（所有业务模块自动获得）

这些能力不需要业务代码参与，继承框架基类即得：

| 能力 | 说明 |
|------|------|
| 元数据驱动列表页 | 后端序列化器声明字段 → 前端自动生成搜索区 / 表格列 / 表单（`RePlusPage`） |
| 三层权限 | 接口 + 菜单权限码、数据行可见范围、字段可见性，全部 fail-closed |
| 回收站 | 软删除模型的回收站列表 / 恢复 / 物理清除 |
| 变更历史 | 行级操作审计与字段级 diff 回溯 |
| 导入导出 | 导入校验 / 异步导出 / 导出下载中心 |
| 批量操作 | 批量删除 / 批量启用停用（可纳入审批拦截） |
| 代码生成器 | `generate_crud` 一条命令产出后端四件套 + 前端页面 + 菜单种子 |
| 模块化裁剪 | 每个功能可整体关闭（菜单 / 接口 / 定时任务同步下线，数据保留） |

## 三、快速体验各能力

装好系统后（见[快速体验](./quick-start.md)），用 `--with-demo` 灌入的演示数据可以逐域体验：

| 想看的 | 去哪 |
|--------|------|
| 元数据列表页全貌（字段类型 / 关联 / 附件 / 分组表单） | 示例 → 图书管理（demo.Book） |
| 审批流引擎（提交 → 审批 → 回写终态） | 图书「提交上架」→ 审批中心 |
| 敏感操作二次确认（删除先审批） | 图书删除（412 协议，批准后令牌重放） |
| 表单采集（设计器 → 填报 → 数据） | 表单管理 → 我的填报 |
| 数据分析（数据集 → 仪表盘 → 大屏） | 数据分析 → 数据集 / 仪表盘 / 大屏 |
| AI 助手 / 知识库 | AI 助手（问答 / NL 查数 / 动作卡） |
| 聊天室 | 消息中心（@提及 / 附件 / 线程回复） |
| 开放平台 / Webhook | 集成 → API 应用 / 事件订阅 |

演示数据可用 `python manage.py seed_demo_all --reset` 随时重置，
`python manage.py seed_demo_clean` 一键卸载。

## 四、按部署形态选择功能面

| 场景 | 建议 |
|------|------|
| 直接使用全部功能 | 默认（`full` 预设），无需任何配置 |
| 二次开发起点 | `standard` 预设：内核 + 标配，去掉聊天 / AI / 分析等可选模块 |
| 最小后台（只要权限与配置） | `core` 预设：仅内核模块 |

细节（依赖关系 / 停用语义 / 后台覆盖）见[功能裁剪（模块化）](../advanced/module-trim)；
模块的架构决策见后端仓库
[ADR-045](https://github.com/nineaiyu/xadmin-server/blob/dev/docs/adr/ADR-045-modular-trimmable-architecture.md)。
